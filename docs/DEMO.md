# Demo script (~3 minutes)

1. Open http://localhost:3000 — login as `admin@company.local`
2. **Dashboard** — total employees, avg by currency
3. **Employees** — search, paginate, create one employee, edit, delete
4. **Insights** — pick country, show min/max/avg/median and job title breakdown
5. **Admin** — view roles and users
6. Mention: `pnpm seed:employees` for 10k data, `pnpm test`, GitHub CI
